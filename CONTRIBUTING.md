# Contributing

Thank you for your interest in contributing to this project.  Please read
the guidelines below before you submit a change.

## Preparing a Change

Contributions are made through pull requests on GitHub.  To prepare one:

1. Fork the repository and create a new branch for your contribution.
2. Follow the existing code style and conventions.
3. Add tests for any new functionality or bug fixes.
4. Make sure that all tests pass by running `go test ./...`.

## Submitting Changes

Once your branch is ready, open a pull request as follows:

1. Push your changes to your forked repository.
2. Create a new pull request against the `main` branch of this repository.
3. Give the pull request a clear and descriptive title.
4. Describe the changes you made, the problem they solve and any other
   relevant details.

## Code of Conduct

This project follows the [Go Community Code of
Conduct](https://go.dev/conduct).  Everyone who participates is expected to
uphold this code.

## Questions

If you have a question, or are unsure whether a change would be welcome,
please open an issue on GitHub.
